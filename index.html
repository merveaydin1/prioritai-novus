How the engine works

Scoring model

1. Eligibility gate

Checks whether the problem, owner, expected benefit and data source are clear enough to score.

2. Weighted score

Calculates a 0–100 priority score using value, feasibility, data readiness, strategy, urgency and user impact.

3. Explainability

Generates a plain-language summary, risk flags, next step and suggested project track.
